# 🔍 Code Review Guidelines

## ✅ Check Before Approving

### 1. Functionality

* API runs
* No crash

---

### 2. API Contract

* Input correct
* Output correct

---

### 3. Code Quality

* Clean structure
* Functions separated

---

### 4. Git Practice

* Small PR
* Clear commit message

---

## 🚦 Decision

* Approve → Good to merge
* Request Changes → Minor issues
* Reject → Broken or wrong format

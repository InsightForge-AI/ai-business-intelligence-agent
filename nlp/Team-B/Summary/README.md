
## Description
This module generates a simple summary by extracting the first two sentences from input text.

## Files

preprocess.py  
- Cleans input text

utils.py  
- Splits text into sentences

summarizer.py  
- Generates summary

## How to Run

Run the following command:

python summarizer.py

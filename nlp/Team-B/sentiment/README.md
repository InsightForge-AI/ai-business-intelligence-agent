# Sentiment Analysis

## Description
This file performs basic sentiment analysis using keywords.

It classifies text as:
- Positive
- Negative
- Neutral

## How to Run

Open terminal in this folder and run:

python sentiment.py

## Dummy Inputs Used

- This product is excellent
- Very slow delivery
- The service is okay
- Amazing quality
- Worst experience

## Sample Output

Input: This product is excellent -> Output: positive  
Input: Very slow delivery -> Output: negative  
Input: The service is okay -> Output: neutral  
Input: Amazing quality -> Output: positive  
Input: Worst experience -> Output: negative
